# AgriVision 🌱
**Your Personal AI Farming Companion**

AgriVision is an AI-powered personal farming assistant that combines crop advisory, 
disease detection, IoT-based soil monitoring, and a farm labour marketplace — 
designed for farmers, casual gardeners, agricultural laborers, and FPO/cooperative 
managers across India.

Built for Smart India Hackathon 2026 under the theme **Agriculture, Food Tech & 
Rural Development**.

## Key Features
- 🌾 AI-based crop recommendation using soil, weather, and season data
- 🔬 Disease detection via image-based CNN model (Disease Scan)
- 💧 Live IoT soil pH & moisture monitoring with auto-irrigation
- 🌦️ Weekly weather forecasts with farming advisory tags
- 💰 Real-time mandi price insights
- 🧪 Fertilizer & pesticide dosage recommendations
- 👷 Farm labour marketplace connecting farmers and workers
- 🗣️ Multilingual voice + chat AI assistant with camera support
- 👥 Multi-role support: Farmer, Home Gardener, Farm Labour, FPO Manager

## Tech Stack
**Frontend:** Flutter, Dart, React.js, Tailwind CSS  
**Backend:** Python, FastAPI, REST API, PostgreSQL, Firebase  
**AI/ML:** Scikit-learn, TensorFlow, PyTorch, OpenCV, LLM-based chatbot  
**Hardware:** ESP32, soil pH sensor, capacitive soil moisture sensor, relay-controlled irrigation pump  
**Cloud:** AWS, Firebase, Docker
